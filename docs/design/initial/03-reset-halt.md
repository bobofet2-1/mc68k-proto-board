Component Pinouts Used

DS1813-5 (SOT-23, 3-pin)

   ┌──────┐
 1─┤GND   │
 2─┤VCC   │
 3─┤/RST  │  ← open-drain output
   └──────┘

74HC14 (DIP-14) — using gate 1 only

         ┌────┬────┐
    1A ──┤ 1  │ 14 ├── VCC
    1Y ──┤ 2  │  7 ├── GND
         │    │    │
   (2A ──┤ 3  │ 13 ├── 6A)  ← unused gates
   (2Y ──┤ 4  │ 12 ├── 6Y)
   (3A ──┤ 5  │ 11 ├── 5A)
   (3Y ──┤ 6  │ 10 ├── 5Y)
         └────┴────┘
           (7=GND, 8=4Y, 9=4A)

74HC07 (DIP-14) — using gate 1 only

         ┌────┬────┐
    1A ──┤ 1  │ 14 ├── VCC
    1Y ──┤ 2  │  7 ├── GND   ← open-drain output
         │    │    │
   (2A ──┤ 3  │ 13 ├── 6A)  ← unused gates, leave inputs tied to GND
   (2Y ──┤ 4  │ 12 ├── 6Y)
   (3A ──┤ 5  │ 11 ├── 5A)
   (3Y ──┤ 6  │ 10 ├── 5Y)
         └────┴────┘

MC68000 (DIP-64) — relevant pins only

   Pin 14 → VCC
   Pin 16 → GND
   Pin 17 → /HALT   (bidirectional open-drain)
   Pin 18 → /RESET  (bidirectional open-drain)
